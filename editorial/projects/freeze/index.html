Freeze

Keeping a fleeting interface still

A screen-review tool for preserving menus, hover states, and other fleeting UI before annotating them or inspecting a recording frame by frame.

The question

How do you review a state that disappears when you try to capture it?

Inside the project

The context

Opening a capture interface can change the very state someone wants to review. Freeze captures the screen before its own window appears, keeping the review tool out of the evidence.

Recorded choices

  • Capture before showing the overlay so the original interface state remains intact.
  • Step through recordings using frame presentation times rather than assuming an even frame rate.
  • Make annotated evidence readable by people and agents through image and structured review exports.

Working notes

A story about designing the tool around the evidence, then making the handoff useful beyond the person who captured it.
