GitHub Copilot on mobile

Making agent work legible on a phone

Design work on the mobile Copilot experience: making agent sessions easier to follow, reducing timeline noise, and exploring clearer ways to get started.

The question

How do you make an agent’s work readable and actionable on a small screen?

Inside the project

The context

An agent session can become a long stream of updates on a small screen. The timeline exploration removes an expansion gate, reduces card styling, and groups consecutive tool activity. Native prototypes provide a separate way to work through first-run explanations, navigation, and screen states.

Recorded choices

  • Explore a flat timeline so the session does not sit behind an extra expansion gate.
  • Group consecutive tool activity to reduce noise while keeping the detail available.
  • Use native prototypes to examine copy, navigation, and screen states in context rather than relying only on static mockups.

Working notes

A story about making asynchronous work understandable on mobile: what should stay visible, what can be grouped, and where a person needs a clear next step.

A proposed case-study direction, not a claim about a shipped outcome.

Sources & status

Public session-timeline design notes and local Copilot prototype sessions. Shipped scope is still to be confirmed.
